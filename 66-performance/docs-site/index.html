Course Hub API

Course Hub is the example project of FastAPI Mastery: Zero to Production by Nilesh Technology. Every request goes through nginx: HTTPS, compression, limits and security headers happen there, and the API answers behind it.

Endpoints

MethodPathWhat it does
GET/health/live the process is alive
GET/health/ready the database is reachable and at the head revision
GET/courses every course: id, title, description, level
GET/courses/{id} one course - 404 when it doesn't exist
POST/courses a new course: 201 + a Location header, at most 2 a second
GET/whoami what the app believes about your request: client, scheme, url

Limits

10 requests a second per IP address, bursts of 20. Writes: 2 a second, bursts of 4. Too many requests get 429. Bodies over 1 MB get 413.

Request ids

Every answer has an X-Request-ID header. Quote it when you report a problem: the same id is in nginx's access log and in the API's log.
